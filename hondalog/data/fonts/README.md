# Bundled fonts

Loaded at start with `QFontDatabase.addApplicationFont` (hondalog/ui/theme.py).

| Files | Font | Licence |
|---|---|---|
| `Inter-{Medium,SemiBold,Bold,ExtraBold}.otf` | Inter 4, (c) 2016-2023 The Inter Project Authors, https://github.com/rsms/inter | SIL Open Font License 1.1 |
| `JetBrainsMono-{Medium,Bold,ExtraBold}.ttf` | JetBrains Mono 2.304, (c) 2020 The JetBrains Mono Project Authors, https://github.com/JetBrains/JetBrainsMono | SIL Open Font License 1.1 (`OFL-JetBrainsMono.txt`) |

Both are under the same licence text; see `OFL-JetBrainsMono.txt` or
https://openfontlicense.org. If the files are missing the app falls back to
DejaVu Sans / DejaVu Sans Mono.
